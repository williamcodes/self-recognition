    Method

    One passage

    Did you write this? Half the samples come from the reader and half from another model.

    Two passages

    Which did you write? Both authors answer the same prompt. The location of the reader’s passage is balanced.

    One folder

    One author wrote both files. The reader can request their contents before deciding yes or no.

    Two folders

    Each folder holds two pieces from one author. The reader chooses which files to open and identifies its folder.

    The main score accepts explicit labels such as “Passage B”. Exact scores require the label alone. Invalid answers count as misses. Folder reads use a text command. Scores can reflect instruction following, stylistic differences, and quality cues. Reused passages make trials dependent.
