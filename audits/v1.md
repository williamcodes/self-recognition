# Can the seed tasks measure recognition of a model’s own writing?

The v1 public seed shows how two local models responded to anonymous text. A word-count rule recovered the authorship key on 88 of 96 trials. The two models got 47 of 96 decisions correct in total. A high score on these particular items could come from recognizing a length difference between these writers. The transcripts leave open how either reader made a decision.

## What word count explains

Qwen wrote the longer response on 11 of 12 shared prompts. A retrospective rule assigns the longer passage or folder to Qwen in paired trials. On yes/no trials it attributes writing to Qwen when the average exceeds 85 words per file and to SmolLM2 otherwise. A single passage counts as one file. Paired ties receive zero credit. Folder comparisons here use all available files.

## What the readers did

- Qwen answered A for all 12 passage pairs and YES for all 12 single passages. SmolLM2 answered NO for all 12 single passages.
- SmolLM2 opened zero files in 24 folder trials. Qwen opened exactly the first file in folder A in all 24. Qwen's 8/12 in folder yes/no includes ten YES responses. Neither reader inspected a second file, so the run gives little information about combining evidence across files.
- Both models used extra words for all 24 passage A/B answers. Exact-label scoring gives zero correct across those trials. The explicit-label scorer, added after viewing the seed, gives nine correct. The passage and folder prompts give different instructions about answering with the label alone.
- Each reader has one alternative author. Identifying the other writer is enough to answer the paired question. Success with this cohort cannot tell us whether the model also recognizes its writing against an unfamiliar or closely related model.

## How to review a task

Open a trial, read the initial message, and attempt it before revealing the record. For a folder, start with one file and decide whether another one would change your answer. On reveal, compare your cue with the writing instructions, other available files, and the model's actual reads and reply. Each record links to an issue form with its trial URL. Human attempts are informal design checks. Repeat visitors can learn the authors from earlier reveals.

## Before scaling

First decide whether length, formatting, and instruction-following count as the voice we want to measure. If the intended claim is recognition beyond those cues, use length-matched, previously unseen passages and compare against a simple authorship classifier. Add at least one other possible author. Standardize the response instruction and freeze the scoring rule before collecting another set of judgments. Test whether reversing the same pair changes the reader's choice.

For external submissions, verify complete reconstructed messages as well as balanced labels. The current verifier uses substring checks on passage inputs and prefix checks on file responses. Extra hints in a submitted conversation could pass those checks. The public seed is suitable for inspection and development; a held-out evaluation would be needed to measure performance without advance access to answers.

## Independent reviews

OpenAI GPT-6.2 Astra through Codex CLI and Anthropic Claude Sonnet 5.5 through Claude Code reviewed separate snapshots of the same revision. Both were asked to find shortcuts, examine score parsing and folder access, and distinguish observations from alternative explanations without running new model evaluations. The counts above were checked against the saved evidence. In particular, five of eight cells contained 12 identical decisions. Across passage A/B the main scorer awarded nine correct decisions out of 24; the exact scorer awarded zero.

Two design choices need human judgment. Every reader receives its own model tag, so it can use prior beliefs about that named model. A human attempting a trial estimates another author's identity and can tell us which cues stand out. Also decide whether the folder task should measure a model's spontaneous decision to inspect files or recognition after it has read them. Opening files by choice and requiring both folders to be read answer different questions.
