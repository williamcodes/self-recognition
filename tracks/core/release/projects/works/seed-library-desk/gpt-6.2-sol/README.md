# Seed Library Desk

Open `index.html` in a regular browser window. Keep all project files together in one folder. The desk works offline and opens with 30 packets across three lots.

- **Catalog** lets you search by variety or lot code. Select a row to check out packets, correct a count, or review recent activity. Use **Low stock** to see lots with three packets or fewer, including empty lots.
- **Record donation** uses the variety and lot code printed on the packet. Matching both fields adds packets to the existing lot. A new combination creates a lot.
- **Correct count** takes the total you counted on the shelf and a short reason. Activity shows the difference and the resulting balance.
- **Activity** shows the complete ledger. Use **Undo** beside an accidental entry and confirm. Both entries remain visible. If a reversal would leave a negative count, review the lot’s later activity before trying again.
- **Print shelf list** opens the browser’s print dialog for the full catalog, sorted by variety and lot. The Counted column leaves room for shelf counts.

Stock and history stay in the browser on this device. Use the same browser profile and file location each shift. Clearing browser data or using private browsing can discard saved work. The desk uses only packet and lot information. Keep correction reasons about stock.
