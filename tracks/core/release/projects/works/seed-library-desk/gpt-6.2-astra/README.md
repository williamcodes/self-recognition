# Seed Ledger

Open **index.html** in a current desktop browser. Keep index.html, style.css, art.js, and app.js together. No installation, account, or internet connection is needed.

Use the same browser profile and file location for each shift. Inventory is saved in the browser's local IndexedDB storage. Clearing site data or closing a private browsing session can erase the ledger.

- Choose **Record entry** for a checkout, donation, or count correction. Enter the actual shelf count and a short reason for a correction.
- For donations, select an existing lot or choose **Create a lot…**. A matching variety and lot code add to the existing balance.
- Choose **View activity** on a lot to see its ledger. **Undo** records a reversal and preserves the original entry. The desk prevents changes that would take stock below zero.
- **Print shelf list** prints every lot, including its packet count and low-stock status, regardless of catalog filters. Lots with three or fewer packets are marked low stock.
