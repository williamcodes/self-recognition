# Bake Ledger

Open `index.html` in a modern browser to use the ledger offline. It starts with four fictional days from November 2026.

- Select **Add day** to record a date. For each product, enter trays baked and individual items left at closing. Enter zero where applicable.
- Select **Edit** on a row to correct counts or the date. Each date has one entry.
- Product cards summarize all recorded days. **By weekday** pools the counts for each weekday. For example, Monday’s bun rate is 12 left ÷ 96 baked = 12.5%.
- Estimated sold is baked minus left at closing. The ledger rounds leftover rates to one decimal place. A dash indicates zero production for that product and period.

Changes are stored in the browser for the local file. Keep opening the same copy in the same browser profile. Use **Download backup** to save a portable copy of the data. **Restore backup** loads that copy into the ledger after you confirm the replacement. Download a backup before moving the file, switching browsers, or clearing browser data.
