# Callboard

Callboard is an offline rehearsal planner for a community theater. Open **index.html** in a regular browser window. Keep the three app files together. No installation, connection, or account is needed.

- Use **New booking**, choose a group from the roster, or select an open time in the calendar. The calendar starts on the nearest preceding half hour. The booking form accepts any minute in 24-hour time.
- Select a booking to move or remove it. The editor lists any conflicts and preserves the original booking until you save a valid change.
- **Print schedule** opens the browser print dialog for a one-page, Monday–Friday schedule. It includes any groups still to book. Choose a printer or save it as a PDF from the dialog.
- On a narrow screen, use **Show day** to change the day you see. Printing always includes the full week.

The same weekly schedule stays in the browser's local storage. Reopen the same file from the same path and browser profile to continue. Private browsing and clearing browser data can discard saved bookings. The app shows a status message if the browser blocks local saving.
