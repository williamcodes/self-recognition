# Kiln Ledger

Open **index.html** in a regular Chrome or Edge window. Keep the four app files together in one folder. The tracker runs entirely offline and needs no installation or account.

The first launch creates students **P01** (4 credits), **P02** (2 credits), and **P03** (1 credit), plus **Tuesday Handbuilding at 18:00** and **Saturday Glazing at 10:00**. The sample dates are set to the next Tuesday session and the Saturday that follows it. Each workshop has eight seats.

## At the studio

- Select a workshop and choose **Reserve seat**. The reservation holds one seat and leaves the student's balance alone. Each student can hold one seat per workshop.
- Choose **Mark attended** to spend one credit. If the student has no credits left, use **Add credits** before recording attendance.
- Choose **Cancel** to release a reserved seat. A cancelled student can book again if a seat is available.
- Choose **Correct** on an attended row to return the credit. Choose **Reserved** to keep the seat or **Cancelled** to release it, then enter a reason. The original attendance and the credit adjustment both stay visible in **Balance history**.
- Use **Add workshop** to enter a name, date, and start time. Open **Students** to add students, add prepaid credits, or view a student's balance history.

## Saving and backups

Changes save automatically in the browser profile at the file's current location. Reopen the same file in the same browser profile to pick up where you left off. Use **Backups → Download backup** before moving the files, switching browser profiles, or clearing browser data. Use **Restore backup** to load a copy. Restoring replaces the ledger currently open in the browser.
