# Kilnbook

Open **index.html** in a current desktop browser. Keep the files together and use the same browser profile and file location each time. All artwork, scripts and styles are included. Records are saved in the browser’s IndexedDB. Clearing browser data or closing a private browsing session can erase them.

The two sample workshops are dated for their next local occurrence when the register first opens. Each is a single session with eight seats.

Use **Open register** to reserve a seat, mark a student attended, or cancel a reservation. Attendance requires one available credit. To remove an incorrect attendance mark, choose **Correct attendance** and enter a reason. This restores the credit and returns the student to reserved. Cancel the reservation as well if the seat should be released.

Select a student under **Student credits** to see dated changes, adjustments and running balances, or add purchased credits. The plus button beside Student credits adds a new student code.
