How costs are calculated

Each month starts with a fresh page allowance. Monthly cost equals the base fee plus the overage rate multiplied by pages above the allowance. Between 800 and 1,400 pages, break-even solves $29 + $0.065 × (pages − 800) = $53. Beyond 1,400 pages, Plan A’s overage rate is higher, so Plan B stays cheaper.

Usage changes apply to each month before pricing, with half-pages rounded up. Costs use the full per-page rates. Totals and savings are each rounded to cents after calculation, so subtracting the displayed totals can differ by one cent.
