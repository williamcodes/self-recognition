Museum Education Arrival Planner

Open index.html in a recent desktop browser. Keep index.html, styles.css and
planner.js together. The planner works offline without an account or server.

1. Under Arrivals, use the pencil to change a booking's arrival time, visitor
   count or subgroups. Use Add group for another booking. Subgroup sizes must
   add up to the group's visitor count.
2. Choose a plus sign in the space schedule or use Assign slot. Pick the
   subgroup, start time and space. Each subgroup has one 30-minute activity.
   Select an existing assignment to move or clear it.
3. Review any conflicts beneath the schedule. Each space hosts one subgroup
   at a time. Activities may start as soon as the preceding activity ends.
   Changing an arrival leaves assignments in place and flags early starts.
4. Choose Print schedule. The printout lists assignments in time order, with
   arrival times, destinations and visitor counts. Incomplete or conflicting
   plans print with a Draft notice and the items that need attention.

The first visit opens a ready-to-edit sample with 51 visitors. Changes are
saved in the current browser when local storage is available. Reopen the same
file from the same location in the same browser profile to continue the draft.
If the browser blocks local storage, changes last for the current session.
