# Neighborhood bus stop survey

- [Meeting poster](bus-stop-poster.pdf) is an 18 × 24 inch portrait display. Print at actual size.
- [Survey handout](bus-stop-handout.pdf) fits one US Letter page and shows every count, share, and response total.
- [Survey counts](survey-counts.csv) contains the six original count records in spreadsheet-ready form.

The surveys are fictional. Each respondent picked one option. Percentages use the total for the same stop and month. The poster uses whole percentages and the handout uses one decimal place.

To regenerate the PDFs offline, run `python3 source/render.py` from this directory with `rsvg-convert` available.
