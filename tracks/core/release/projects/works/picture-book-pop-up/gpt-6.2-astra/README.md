# Fold and Find

A print kit for a one-room exhibition of 18 handmade picture books. The accordion, pull-tab and open-book characters link each table to the entrance sign, activity sheet and object labels.

## Print kit

| File in Print | Use |
| --- | --- |
| 01 Entrance.pdf | One welcome sign at the door |
| 02 Table signs.pdf | One sign per table, in table number order |
| 03 Family finding sheets.pdf | Two identical take-home sheets per page. Cut across the middle. |
| 04 Book labels - fillable.pdf | Six labels per page, one page per table. Fill in the actual titles and techniques or write on the lines after printing. |

Use white US Letter paper, single-sided, at actual size. The first two numbered slots at each table are for the books visitors may handle. Place the four display copies with their corresponding “Look only” labels. The hand and eye symbols carry these instructions in grayscale as well.

## Updating the exhibition

[Setup and updates](Staff/Setup%20and%20updates.pdf) covers layout, form editing and replacement printing. Keep one saved, editable copy of the labels as the inventory master. When changing a title, check that the text is legible at print size.

## Identity files

The four SVG files in Identity can be scaled for new signs. Use the same table names, numbers and characters throughout. Keep the artwork on white paper. Use solid black for text and outlines and blue (#164AB7) for the accent. For two-ink duplication, assign all blue artwork to the same blue ink. The wordmark uses outlined lettering so it can be placed without installing fonts.
