# Fold and Find

A print kit and editable book register for a one-room exhibition of 18 handmade picture books. The numbered table symbols guide families to paper folds, movable pieces and illustrated stories. Each book label tells visitors whether they can handle the book.

## Print and install

Start with the [setup and visual identity guide](staff/setup-and-identity.pdf). Print single-sided on ordinary white US Letter paper at Actual Size or 100%. The PDFs contain black and a single named Vermilion spot color. The numbers, table symbols and hand/eye handling symbols also work in grayscale.

| Material | Copies and placement |
| --- | --- |
| [Welcome poster](print/01-welcome.pdf) | One at the entrance, with Book Hunt cards and pencils nearby. |
| [Table signs](print/02-table-signs.pdf) | One set. Place each numbered sign where visitors can read it from the aisle. |
| [Book Hunt cards](print/03-book-hunt.pdf) | Two cards per sheet. Cut across the dashed center line. |
| [Starter book labels](print/04-book-labels.pdf) | One set makes 18 labels, six per table. Cut along the dashed grid. |

## Fit the labels to the books

Open [Book register](staff/book-register.html) in a modern browser. Keep the files in the `staff` folder together so it works offline. The starter labels use shelf IDs and looking prompts because the book inventory was unspecified. The first two slots on each table are provisionally marked **TRY IT**. Before opening, match the books to their IDs and verify the two handling books at each table.

Edit a shelf ID to add the real title and tailor its prompt. Download the complete PDF or one replacement label. When swapping a handling book, clear the old slot, mark the replacement and reprint both labels. Save a register backup after editing, then use **Open a backup** to continue on another browser or computer.

Label PDFs support Western European letters and common punctuation. The live preview flags text that exceeds the label space or uses unsupported characters. A saved backup also works when browser storage is disabled.
