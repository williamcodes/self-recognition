# One poster, two inks

An open house built around *Tidal Signal*, a fictional poster. Visitors handle three stocks, compare four ink pulls, then choose among three finished prints. Send up to six visitors to Paper every 15 minutes. Each group follows the same route in about 26 minutes.

## Set up and print

Start with the [staff guide](<04 Staff/Staff guide.pdf>) for the floor layout, staff assignments, sample schedule, and press instructions.

| File | Print and use |
| --- | --- |
| [Visitor signs](<01 Visitor signs/Visitor signs.pdf>) | Four 11 × 17 in landscape signs for Welcome, Paper, Ink, and Gallery. |
| [Cut sheets](<02 Cut sheets/Cut sheets.pdf>) | Three Letter landscape pages for route cards, tray labels, and gallery and ink-pull labels. Print at 100%. Print three copies of page 1 per group of six, plus spares. |
| [Poster plates](<03 Poster artwork/Poster plates.pdf>) | Three aligned 11 × 17 in portrait plates for the finished posters. |
| [Swatch plates](<03 Poster artwork/Swatch plates.pdf>) | Three aligned Letter landscape plates for four swatches per sheet. |
| [Poster color proofs](<03 Poster artwork/Poster color proofs.pdf>) | Page 1 is the overprint for A on smooth white and B on natural stock. Page 2 is the knockout for C on the same stock as A. |
| [Swatch color proofs](<03 Poster artwork/Swatch color proofs.pdf>) | Pages 1–4 show Ink A only, Ink B only, overprint, and knockout. Use page 3 on all three stocks for the Paper station if working from these proofs. |

For two-ink printing, each plate file uses the same page order. Page 1 is orange for overprint, page 2 is blue for both versions, and page 3 is orange for knockout. Print the appropriate orange plate first, then the blue. The colored PDFs simulate the crossing and can also be used on a composite printer. If you use them for display, tell visitors they are printed simulations and that actual ink interactions vary with the press and stock.
