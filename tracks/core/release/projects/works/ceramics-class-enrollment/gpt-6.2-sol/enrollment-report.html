Consider a small Saturday capacity trial

Saturday filled in February and March, with requests rising from 4 to 7. January had 2 open seats, so test added capacity on one run. Keep Tuesday capacity as a baseline. It drew 6 requests in January but had an open seat in February.

Occupancy is enrollments divided by seats offered. Quarter figures use summed enrollments and seats for each session.

Waitlist requests are counted per run. A person may appear on both session waitlists, so combined counts can include the same person more than once.
