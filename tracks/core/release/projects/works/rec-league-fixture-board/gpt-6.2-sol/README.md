# Thursday Fixtures

Open **index.html** in a regular Chrome window. Keep the three app files together. The board runs offline from the folder and needs no installation, server, or account.

1. Use the date field or the week arrows to select a Thursday. Each date has its own evening schedule.
2. Select **Add pairing** for a time and table, choose two teams, and select **Save pairing**. Select any scheduled match to change or clear it.
3. The schedule check flags teams booked on both tables in the same slot. The editor also flags the conflict while you pick teams. You can save a conflict temporarily while rearranging matches.
4. Select **Print evening sheet**. Use portrait, 100% scale, and turn off browser headers and footers. The one-page layout works on Letter or A4. Conflicts appear on the sheet if they are still present.

Changes save in the current browser profile. Reopen the same file from the same location in the same profile. Private browsing, switching profiles, moving the app, or clearing browser site data can make previously saved fixtures unavailable.
