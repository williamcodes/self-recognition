# Saturday linen board

Open [index.html](index.html) in a modern browser. The file runs offline and needs no installation. Keep opening the same file in the same browser profile to pick up saved changes. If the header says changes last for this session, keep the tab open until you finish.

1. Set **Prepare by** to the Saturday time you want to check. The room plan shows which arrivals have enough linen by that time. It assumes rooms are accessible for cleaning and measures linen availability only.
2. Select **Reserve** to hold the full clean kit for an arrival, or **Release** to put it back. Available counts exclude held linen. Reservations get priority in the time preview, followed by the other arrivals in room order.
3. Select **Record return** when laundry arrives. Enter its actual Saturday time and the total clean quantities received for this batch, including any zero counts. Use **Edit return** to correct or update that record. The expected quantities stay on screen, and the preview uses the actual quantities and time once recorded.
4. Use **Edit opening count** if the Saturday starting count differs from the board. Enter quantities from before the laundry delivery and reservations.

The board starts at noon. Rooms 1, 2 and 4 can all be supplied from opening stock. Holding linen for all three leaves 0 queen sets, 1 twin set and 2 towels available before the return.
