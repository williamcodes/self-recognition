# Mending Table

Open **index.html** in a regular Chrome window on the café laptop. Keep the four application files together. The desk works offline from the first visit.

## At the table

1. Enter a garment description and choose its repair. Choose **Other repair** to describe a different request. Use garment details only. Leave out names and contact information.
2. For more garments from the same visitor, select **Add another item**. Save the intake after entering one to three garments.
3. Write the assigned ticket number on each garment tag. The confirmation pairs every number with its garment. Give the visitor the matching numbers for pickup.
4. Find a ticket by number, garment, or request. The status filters narrow the queue. Use the menu beside an item to select **Waiting**, **In progress**, or **Ready**. To correct a mistake, choose the intended status in the same menu. An item may move out of the current filter. Choose **All** to find it again.

## Between sessions

Saved tickets stay in this browser profile after refresh or restart. Ticket numbers continue across monthly sessions. Keep using the same browser, profile and file location. Moving the file, using a private window, or clearing browser data can make records unavailable. Unsaved form entries are temporary.
