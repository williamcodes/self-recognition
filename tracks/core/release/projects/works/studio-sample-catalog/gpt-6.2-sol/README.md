# Selvedge Studio · Swatch catalog

Open **index.html** in a regular Chrome window on the shared laptop. Keep the project files together and use the same browser profile and file location for all three staff members. The catalog runs offline and opens with 24 fictional swatches across drawers A–F.

## At the counter

- Press **/** to search. Type a paper tag such as `C-014` or `c014`, a color, a fabric, or a client or project reference. Press **Enter** to open an exact code or the only matching result.
- Use the color, fabric, drawer, and status filters together. The three totals above the inventory also set the status filter. Tab to the drawer choices and use the arrow keys to change drawers.
- Open **Edit** to correct a record. To send a swatch out, select **Checked out** and optionally enter a client or project reference. On return, select **In cabinet** and save. Returning a swatch clears its checkout reference. The drawer field tracks where the swatch belongs.
- Press **N** outside a text field to add a swatch. Codes are unique and saved in uppercase. A new code beginning with A–F and a hyphen suggests a drawer when the drawer field is empty. Press **Esc** to close a dialog.

## Keep a copy

Changes are saved in the current browser profile. Use **Export data** to save a spreadsheet copy (**CSV**) or a restorable catalog backup (**JSON**). Both exports contain every record, regardless of filters.

To replace the fictional records with your own, choose **Export data → Start a blank catalog** and confirm. To recover the catalog after clearing browser data, or to move it to another folder or laptop, open the catalog at the destination, choose **Export data → Restore from a backup**, select your JSON file, and confirm the replacement.
