# Selvedge · Upholstery sample catalog

Keep the project folder together and open **index.html** in a desktop browser. The catalog works offline with no install or sign-in. On first use, it starts with 18 fictional samples, including five client loans. The fabric illustrations represent color and weave.

## At the counter

- Press **/** to search. Type a tag such as **C-014**, a swatch name, or a client. **Enter** opens the first match. **Down Arrow** moves focus to the first result.
- Combine drawer, color, and fabric filters. Select **With clients** to find outstanding loans. Grid and list views show the same records.
- Open a sample and select **Check out**. Enter the client or project and press **Enter**. When it comes back, open the record and select **Return to studio**. File it in the drawer shown.
- Select **Edit record** to correct a tag, drawer, fabric, color, name, or borrower. The drawer can change independently of the paper tag.
- Press **N** outside a field to add a sample. Each code uses A–F, a hyphen, and three digits. **Tab** moves between controls, and **Esc** closes the record without saving pending form edits.

## Shared laptop and copies

All three staff should open the same file at the same path in the same regular browser profile. The browser stores saved records locally. Private browsing, clearing browser data, switching profiles, or moving the file can remove access to that copy.

**Export CSV** downloads the entire catalog, including borrower names, even when the view is filtered. Save dated copies somewhere the studio can find them. The CSV opens in spreadsheet software. Changes made in a spreadsheet stay in the exported copy.
