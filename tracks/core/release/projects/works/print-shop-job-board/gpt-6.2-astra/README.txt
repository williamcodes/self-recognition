FOLIO COPY SHOP
Open index.html in a browser with local storage enabled. No installation or internet connection is needed.

Use the same browser profile and file location on the shop computer for both staff members. Orders are saved in that browser. Clearing its site data removes saved orders.

On first use, the board assigns the sample orders to the next Tuesday (today if it is Tuesday) and the following Wednesday. Click any job to set its actual deadline or change its stage in either direction. Use New job for incoming orders.

At Pickup, enter only the number collected on this visit and save. The board subtracts that amount from the outstanding count. Fully collected orders leave the active board and queue.

Print daily queue prints the current outstanding workload grouped by the next shop action. Each group lists the earliest due job first, including overdue work and upcoming jobs staff can begin today.
