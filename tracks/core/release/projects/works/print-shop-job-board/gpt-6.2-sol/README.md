# Copy Desk

Open **index.html** in a regular browser window on the shop computer. Keep all three app files together. The board works offline and saves orders in that browser profile. Both staff should use the same profile and open the same file. Keep the file in a fixed location and retain the browser’s site data to preserve the board. Orders do not sync between computers or browser profiles.

## At the counter

- Select **New job** and enter the order quantity, stage, and local due date and time. Select a job’s name to edit its details.
- Use the forward action or the back arrow to move between Intake, Proofing, Ready to Print, Printing, and Pickup.
- In **Pickup**, select **Record pickup** and enter the number of copies handed over. The remaining count updates immediately. Select the job name to see pickup history. Fully collected orders move to the **Completed** filter.
- A job becomes **Overdue** after its due time while it still has outstanding copies. Use the filter to find overdue jobs or jobs due today.
- Open **Daily queue** to see all open work grouped by the next staff action, with the earliest deadlines first in each group. **Print queue** opens the browser’s print dialog for that same list, regardless of the current board filter.

The initial orders are dated Tuesday and Wednesday of the shop computer’s current week on first open. Change their dates from the job cards.
