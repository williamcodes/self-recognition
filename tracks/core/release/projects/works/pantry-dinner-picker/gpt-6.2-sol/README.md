# Pantry Table

Open **index.html** in a modern browser. Keep the project files together. The dinner picker runs entirely offline and requires no installation or account.

- Use the serving controls to compare recipes. Each card shows the amount needed and the exact shortage for any missing ingredient.
- Choose **Add ingredient** to add stock. Adding the same name and unit increases the existing amount. Select a pantry row to set its current amount, including zero.
- Choose **Add recipe**, enter the number of servings the recipe normally makes, and enter the ingredients for that batch.
- When a recipe is ready, choose **Cook this meal** to review the quantities. **Confirm meal** deducts the entire batch. Canceling leaves the pantry as it was.

Ingredient names match regardless of capitalization and extra spaces. Use consistent names such as “Eggs” across the pantry and recipes. Grams and whole items are tracked separately, even for ingredients with the same name. Scaled whole-item amounts round up. Gram amounts stay exact and are shown as fractions when needed. Gram inputs accept decimals and fractions such as `2/3`.

Changes are saved in this browser for this copy of the app. Open it from the same location and browser profile to continue with the same pantry.
