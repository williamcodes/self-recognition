# Agentic authorship pilot

The primary question is whether an A/B judgment that Astra gets right inline becomes difficult when it must navigate a workspace. Each reader receives an empty, fresh Codex session. Both writers receive the same underlying facts. Two presentation orders per case keep the answer key balanced, but do not double the independent topic count.

Development uses the eight prior shift-handoff topics (packet pilot rounds 5a and 5b). The primary cross-family comparison is Claude Fable 5.2 versus GPT-6.2 Astra. The companion comparison is sibling GPT-6.2 Sol versus GPT-6.2 Astra. Model identities are hidden in workspaces. Credits, timestamps and source-file identifiers are excluded. Each folder assignment is swapped, including the bodies of associated files. Retrieval trials have unrestricted read-only terminal access. Inline controls receive the exact same paths and document contents in a fresh Codex prompt.

The 16 earlier confirmation topics (packet pilot rounds 6a and 6b, all topic IDs 0–15) are reserved before this series for final workspace evaluation. They are held out from this series' design rounds. Their single-document results were already known. An independent check will use fresh same-brief writing if available. Selection of any cases for diagnostics is labeled. Every completed decision is retained.

Log the terminal commands, complete task files appearing in tool output, decision, order consistency, and reader explanation. Full-file visibility is a conservative measure of access and does not establish attention. The primary outcome is A/B accuracy per opponent, with matched inline and workspace decisions.

A diagnostic follow-up is selected after confirmation using a fixed rule: the first two fresh topics per comparison model for which both inline orders succeeded and at least one workspace order failed. Replay both orders three ways: provide the exact terminal evidence the original reader obtained, provide the verified duty-lead documents, or repeat the unchanged workspace. This outcome-selected diagnostic cannot estimate population accuracy.
