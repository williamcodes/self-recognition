# Stagehand

Open **index.html** in a current desktop browser. Keep it with app.js and style.css. All three files run locally.

### Pack a move

1. Choose **Add box** and give the box a recognizable name. Its numbered label stays the same when you rename it.
2. Choose **Add prop**. Select its box or leave it **Unassigned**. Each prop entry represents one physical item.
3. Open **Unassigned** to find loose props. Choose **Edit** beside a prop to assign it, move it between boxes, or change its notes.
4. Choose **Print inventory** from either tab. The printout includes every box, its contents and notes, then the unassigned props. The browser’s print dialog can also save a PDF.

The local inventory uses browser storage. Reopen the same file in the same browser profile to resume. Moving the files, clearing browser data, or using private browsing can affect access to saved records. If storage fails, the footer reports session-only changes. Print before closing in that case.

### Try it and check the result

Choose **Try a sample move** at the bottom of the page. The sample starts with two boxes, four props, and one unassigned prop.

- Open **Unassigned**, edit **Pocket watch**, choose **Box 02 — Desk dressing**, and save. The watch should now appear beside **Letter opener**, and the unassigned count should read zero.
- Add a box named **Lobby**. Add a prop named **Bell**, leaving its box unassigned. The totals should read three boxes, five props, and one unassigned.
- From **Unassigned**, open **Print inventory**. Check that the preview lists all three boxes, identifies Lobby as empty, and lists Bell under Unassigned props. Cancel the print dialog.
- Reload the sample to restore its starting contents. Choose **Return to local inventory** to resume your own list.
